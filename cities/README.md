# Example cities

Each folder holds `map.json` and `scenario.json`. Run one with

```bash
cargo run --release -p citysim-cli -- run cities/tiny-town --days 2
```

| City | Contents | Use |
|---|---|---|
| `tiny-town` | One main road (600 m), three side streets, 6 buildings, 50 residents, 10 cars, 8 pedestrian crossings (4 with walk signals), 1 traffic light | Quick checks, tests (`crates/core/tests/tiny_town.rs`), learning the model. Runs in a fraction of a second |
| `big-city` | 40 x 40 intersections 120 m apart (4.7 km across), 1,521 buildings, 71,079 residents, about 39,000 car owners, arterials every fifth street, 64 traffic lights; footpaths are derived from the roads and there are no crossings | Scale and congestion experiments. Generated by `citysim generate big`; one simulated day takes about 2.5 minutes; overloaded at the core, so a day ends with about 2,000 gridlock teleports (reported by `run`) |

Regenerate the big city (deterministic):

```bash
cargo run --release -p citysim-cli -- generate big --out cities/big-city
```

Edit either map in the browser editor (`docs/city-editor.md`) and check it with `citysim check-map`.

Simplifications in the current model: vehicles stuck on green with no room ahead for 120 s are removed ("teleported") and their trip counted as done; one lane per segment, no conflict zones or right of way at junctions, no parking, pedestrians do not avoid each other, every day is a weekday, bikes are walkers at 5 m/s.
